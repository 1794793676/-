## 三、提交到远程仓库的流程

1. 从最新 `main` 建分支：

   ```sh
   git checkout main && git pull origin main
   git checkout -b docs/sm-scm-records
   ```

2. 提交并推送：

   ```sh
   git add docs/scm docs/README.md
   git commit -m "docs(scm): 建立实验三站会、配置项与发布记录"
   git push -u origin docs/sm-scm-records
   ```

3. 在 GitHub 用该分支对 `main` 开 PR，描述写：关联任务/交付物、改动与未改动范围、核对方式、风险。
4. 由至少 1 名非提交者评审，在 `评审记录.md` 登记结论后 `--no-ff` 合并，删除分支。
5. 发布条件满足后打注释标签并创建 Release（见 `发布说明-v1.0.0.md`）。

禁止：直接 push `main`、`git push --force`、未经评审合并、把未发生的记录写成已完成。

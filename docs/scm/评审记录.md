## 四、评审规则

1. 每个 PR 至少 1 名非提交者评审，评审人填写姓名与日期后方可合并。
2. 评审意见未解决的 PR 不合并，退回原因保留在 PR 描述中。
3. 合并使用 `--no-ff`，合并后删除远程分支，并在本表登记合并结果。
4. 更新本表单独提交：`git commit -m "docs(scm): 登记 PR #__ 评审结论"`。

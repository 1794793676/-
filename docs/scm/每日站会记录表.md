# 每日站会记录表（Sprint 1 · 模拟记录）

> **教学模拟说明**：本表为实验三教学模拟稿，对应 Sprint 1（US01–US03，26SP、21 项 Task、104 理想小时）的站会过程，用于演示三问法则、5 分钟时间盒与障碍闭环，**不冒充真实运行记录**。日期 D1–D10 为模拟工作日；实际开展时由 SM 按真实日期、时刻与发言替换本表内容。

## 一、站会规则

1. 每日固定时间、5 分钟以内；每人按"昨天完成—今天计划—障碍"发言，每人不超过 2 分钟。
2. 站会不展开技术讨论；障碍由 SM 会后 30 分钟内组织专题小会并跟踪关闭。
3. SM 现场计时并记录，会后立即更新看板（待办 / 进行中 / 已完成 / 阻塞）。
4. 每次站会实测时长 3 分 50 秒 – 4 分 40 秒（模拟记录），均在 5 分钟时间盒内。
5. 参会角色：PO 陈铎锋、SM 何昊锵、Dev 1 陈志成、Dev 2 涂先诚；配置管理员由 SM 兼任。

## 四、记录规则

1. 只记录实际发言要点，不代写他人内容；不确定的事实标"待确认"。
2. 每次站会后当日提交：`git commit -m "docs(scm): 记录 D__ 站会与看板状态"`。
3. 障碍必须与看板"阻塞"列一致，关闭时写清处理动作与证据位置。
4. 正式提交前把模拟日期替换为真实日期，并核对四人姓名与岗位。

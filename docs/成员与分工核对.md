# 成员与分工核对

依据用户最新提供的实验二修订版报告首页，实验三延续四个岗位。以下只记录已有证据，不代表成员已参加实验三站会、审批或代码评审。

| 岗位 | 已知成员 | 实验二记载的分工 | 实验三待核对事项 |
| --- | --- | --- | --- |
| PO | 陈铎锋 | 需求范围、用户旅程、故事排序与 MVP 价值判断 | 本人确认实验三范围、变更审批与验收；GitHub 账号待核对 |
| SM | 何昊锵 | 协作组织、故事地图、骨架与版本规划 | 本人确认站会主持及配置管理职责；GitHub 账号待核对 |
| Dev 1 | 陈志成 | 申请和审核故事、状态流转与验收标准 | 本人确认实际开发及测试贡献；GitHub 账号待核对 |
| Dev 2 | 涂先诚 | 公示和结果故事、权限隐私与验收复核 | 本人确认实际开发及测试贡献；GitHub 账号待核对 |

用户先后提供了两个实验二报告版本，PO 与 Dev 2 人选不同。本表以最新修订版为准。实验二工作区过程记录中的 SM、PO、Dev 属于教学模拟的 Agent 角色，不能据此推断这四位同学亲自执行过对应活动。实验三不得为未亲自操作的成员制作 Git 作者、站会发言、评审或心得。

配置管理员由团队确认。根据指导书，其职责包括配置项识别、版本号管理和变更控制，不能仅由提交者身份推断。

## 二、功能列表

1. **US01 查看通知**：通知列表、详情、申请条件/材料/起止时间；未发布通知返回 404；开放中 / 未开始 / 申请已结束三态。
2. **US02 提交申请**：申请表、材料上传、必填与材料校验、开放期校验、截止后拒绝、同一学生/项目/批次唯一申请、本人权限与幂等回执。
3. **US03 辅导员审核**：管理范围内审核列表与材料查看；通过转"待学院复核"；驳回须非空理由并转"已驳回"；记录审核人、时间、意见；重复动作拒绝。

## 四、已知问题

1. US04 学院复核、US05 学生处公示、US06 最终结果**未实现**，本轮业务出口为"待学院复核"或"已驳回"。
2. US07 补正重提为 V2 规划，US08 统计分析为 V3 规划，均不在本增量内。
3. 材料仅支持 PDF/JPG/PNG 且 ≤10MB；服务端按文件头魔数校验。
4. 仅支持 SQLite 单机教学环境，非校级部署；演示账号与数据为合成数据。
5. 公示脱敏与最终确认尚未进入本增量。
6. 部署需手动初始化种子数据（`python -m scholarship.server --port 8080 --data-dir runtime`）。
7. 上传过程中切换通知可能导致附件归入其他项目的问题**待复现与修复**；若发布前未修复，本条为已知缺陷（见 `docs/scm/评审记录.md` 第三节）。
